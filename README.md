# Genkouyoushi Studio ⛩️

A browser-based worksheet generator for Japanese calligraphy practice (原稿用紙). Add vocabulary, configure repetition patterns, and export print-ready multi-page PDFs — no server required.

## Features

- **Live preview** — the grid updates instantly as you change settings
- **Word manager** — add multiple words, each with independent Solid / Trace / Empty repetition counts
- **Block layout engine** — words are placed as visual blocks that wrap automatically across the page
- **Auto-pagination** — when content exceeds a single page, additional pages are created on the fly
- **Vertical and horizontal writing** — supports both traditional (top-to-bottom, right-to-left) and modern (left-to-right) directions
- **PDF export** — all pages are compiled into a single multi-page PDF at 300 DPI, ready to print

## Getting Started

No build step or backend needed. This is plain HTML, CSS, and JavaScript.

```bash
git clone https://github.com/GMikeru/genkouyoushi-studio.git
cd genkouyoushi-studio
# open index.html in your browser
```
