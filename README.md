# NippoWord - Genkouyoushi Studio ⛩️

A stunning, fully-featured **JavaScript Canvas Web App** for creating professional Japanese calligraphy practice sheets (Genkouyoushi). Built for teachers and students, this generator works 100% offline in your browser and automatically paginates your vocabulary lists into print-ready PDF workbooks.

## Features ✨
- **Live Preview**: See the genkouyoushi paper update in real-time as you change settings.
- **Advanced Practice Mode**: A built-in Word Manager allows you to configure exact repetitions (Solid, Trace, Empty) for each vocabulary word.
- **Auto-Pagination**: The layout engine automatically creates flexible text blocks and generates new pages when space runs out!
- **Vertical & Horizontal Support**: Generate traditional top-to-bottom right-to-left grids, or modern left-to-right grids.
- **Client-side PDF Export**: One click will gather all your generated pages and compile them into a print-ready multi-page PDF document, entirely offline.

## Usage (Local) 🚀
There is no backend or build step required! This app uses vanilla HTML, CSS, and JS.
1. Simply clone this repository.
2. Open `index.html` in your favorite web browser.
3. Start generating your worksheets!
